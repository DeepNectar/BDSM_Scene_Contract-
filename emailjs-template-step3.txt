EMAIL SETUP — FINAL VERSION (app v4.38 DH)
===========================================

ONE SITE ONLY: https://web3forms.com
(EmailJS / FormSubmit / Formspree are REMOVED — every one of them
escaped our HTML into visible source code inside the email body.)

WHY WEB3FORMS RENDERS: it takes the app's styled contract and sends
it as the email's REAL text/html part ("rich text emails"). Nothing
is escaped, there is no template to configure, and Gmail/Outlook
display the styled preview directly in the body.

SETUP ONCE (~1 minute, free, no signup):
  1. Open https://web3forms.com
  2. Type the inbox that should RECEIVE the contracts.
  3. Press "Create Access Key".
  4. Web3Forms emails an activation link + your access key to that
     inbox. Click the activation link ONCE, then copy the key.
  5. In the app: ✉ Email data → ⚙ Email settings → paste the key in
     "Access Key from web3forms.com" → (optionally note the inbox +
     From name) → 💾 Save settings.
  6. Press 🧪 Send render test. The mail must arrive showing BIG RED
     STYLED TEXT. If it does, everything renders — close and press
     🚀 Send now on any day.

IF THE TEST SHOWS TAGS AS PLAIN TEXT:
  • Your key's inbox never confirmed the activation email — re-create
    the key at web3forms.com and click the confirmation link.
  • Make sure you are running v4.38 DH (header badge). Hard-refresh
    with Ctrl+Shift+R so the service worker serves the new files.

PHOTOS: signatures/stamp/logo ride along as public Google Drive
pixel links (files shared "Anyone with the link"), so they display
inline without blowing up the message size.

Your keys are stored ONLY in this browser (localStorage) and are
never uploaded anywhere except straight to api.web3forms.com when
you press Send.

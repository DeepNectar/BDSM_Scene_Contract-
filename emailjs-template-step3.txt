variable sits INSIDE raw-HTML block tags {!!!} ... {!!!} in the
TEMPLATE. The app now sends clean HTML only, so the tags must be in
the template (never in the message value).

---------------------------------------------------------------------
STEP A — Open the template editor
  emailjs.com → Login → Dashboard → "Email Templates" (left menu)
  → click your template: template_obq7xfj

STEP B — Set these fields
  Subject   :  {{subject}}
  Send To   :  {{to_email}}          <-- MUST be exactly this
  From name :  Deep & Honey          (anything you like)
  Reply To  :  {{reply_to}}          (optional but recommended)

STEP C — Replace the ENTIRE body content (this is the key step)
  1. In the CONTENT area click the "</>" button (source-code /
     HTML mode) at the top-right of the editor toolbar.
  2. DELETE everything inside it (all default text and styling).
  3. Paste EXACTLY this single line:

        {!!!}{{message}}{{message_html}}{!!!}

     Correct copy-paste version (choose ONE variable, both work):

        {!!!}{{message}}{!!!}

  4. That is all — no other text, no <p>, no wrapper needed.

STEP D — Save
  Click "Save" (top-right). Then optionally "Test it" with dummy
  values to confirm rendering.
